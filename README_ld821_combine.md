# ld821_combine

Overview
Combines LD821 Time History CSVs.

Features
- GUI file picker
- Pattern matching for Time History
- Logging

Prerequisites
- Python3, pandas

Inputs
- Multiple SLM CSVs with _TimeHistory pattern

Outputs
- Combined sorted CSV

Usage
Run script and pick files.

Example
Select Time History CSVs.

Troubleshooting
Invalid timestamps.
